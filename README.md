# GitLens — GitHub Explorer 

A sleek, dark-themed GitHub profile and repository explorer 
built with **vanilla JavaScript** — no frameworks, no dependencies.

 **[Live Demo](https://algomusemg3.github.io/github-explorer)**

---

##  Features

-  Search any GitHub username instantly
-  View follower stats, following, public repos
- Browse all repositories with sorting and filtering
-  Filter by repo name, language, or description
- Click any repo for detailed modal view
-  Remembers your last searched user

---

##  Built with

- Vanilla JavaScript (zero frameworks)
- GitHub REST API
- HTML5 + CSS3
- Google Fonts (Space Mono + Syne)
